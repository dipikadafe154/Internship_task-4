# Weather Pattern Analysis 🌦️

## Overview

Weather Pattern Analysis is a Python-based data analysis project that helps analyze weather data such as temperature and rainfall. The project calculates key weather statistics and visualizes weather trends using charts.

This project helps beginners learn data analysis, data visualization, CSV file handling, and Python libraries such as Pandas and Matplotlib.

## Features

* 🌡️ Average temperature calculation
* 🔥 Maximum temperature analysis
* ❄️ Minimum temperature analysis
* 🌧️ Total rainfall calculation
* 📈 Temperature trend visualization
* 📊 Rainfall analysis chart
* ⚡ Beginner-friendly Python project

## Technologies Used

* Python 3
* Pandas
* Matplotlib

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open Terminal.
5. Install required libraries:

```bash
pip install pandas matplotlib
```

6. Run the project:

```bash
python weather_analysis.py
```

## Dataset Columns

| Column      | Description       |
| ----------- | ----------------- |
| Date        | Weather date      |
| Temperature | Temperature in °C |
| Rainfall    | Rainfall in mm    |

## How It Works

1. Read weather data from a CSV file.
2. Calculate average temperature.
3. Find maximum and minimum temperature.
4. Calculate total rainfall.
5. Generate temperature trend line chart.
6. Generate rainfall bar chart.
7. Display results in the terminal.
